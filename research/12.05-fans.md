### 12.5. Fans / air duct

Studio-built fan / air-duct MQTT commands. Legacy fans may use `gcode_line` M106 ([§12.15](12.15-gcode-line.md)). Plugin forwards only. Envelope: [§6.2](06.02-mqtt.md). Inbound fan / airduct telemetry: [§12.1.2](12.01.02-fields-thermal-fans.md) / [§12.1.4](12.01.04-fields-device.md).

#### `print.set_fan`

Set a fan speed.

| name | type/values | notes |
|---|---|---|
| `sequence_id` | string | Studio counter; example fixed to `"20000"` |
| `command` | string | constant `"set_fan"` |
| `fan_index` | int | firmware fan index |
| `speed` | int | caller-supplied speed |

**Reply parsing:** Generic sequence callback: `[`src/slic3r/GUI/DeviceCore/DevFan.cpp:90-103`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/DeviceCore/DevFan.cpp#L90-L103)`, dispatched at `DeviceManager.cpp:3594`.

```json
{
  "print": {
    "sequence_id": "20000",
    "command": "set_fan",
    "fan_index": 0,
    "speed": 128
  }
}
```

#### `print.set_airduct`

Select an air-duct mode.

| name | type/values | notes |
|---|---|---|
| `sequence_id` | string | Studio counter; example fixed to `"20000"` |
| `command` | string | constant `"set_airduct"` |
| `modeId` | int | mode ID |
| `submode` | int | mode-specific submode |

**Reply parsing:** Sequence callback: `[`src/slic3r/GUI/DeviceCore/DevFan.cpp:90-103`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/DeviceCore/DevFan.cpp#L90-L103)`, dispatched at `DeviceManager.cpp:3594`.

```json
{
  "print": {
    "sequence_id": "20000",
    "command": "set_airduct",
    "modeId": 1,
    "submode": 0
  }
}
```

Hub: [§12](12-mqtt.md).
