#### `print.get_auto_nozzle_mapping`

Map sliced logical nozzle groups/filaments to physical nozzles (V0 and V1 shapes).

| name | type/values | notes |
|---|---|---|
| `sequence_id` | string | Studio counter; example fixed to `"20000"` |
| `command` | string | constant `"get_auto_nozzle_mapping"` |
| `calibration` | int | V0 flow option |
| `extrude_cali_manual_mode` | int | V0 PA mode |
| `filament_seq` | array<int> | V0 change order, -1 gaps |
| `ams_mapping` | array<int>[33] | V0 packed AMS/slot; default 65535 |
| `fila_info` | array<object> | V0: id,direction,group,nozzle_d,nozzle_v,cate,color |
| `nozzle_info` | array<object> | V0: pos,nozzle_d,nozzle_v,wear,cate,color |
