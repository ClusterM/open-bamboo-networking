### 12.1.5. `push_status` fields — camera / AI (`ipcam`, `xcam`)

Leaf catalogue for camera and AI telemetry in `print.push_status`. Hub / `xcam.cfg` bit decode: [§12.1](12.01-status.md). Commands: [§12.11](12.11-camera.md), [§12.12](12.12-xcam.md).

Catalogue from a full (`msg: 0`) **P2S** frame.

#### `ipcam`

| Field | Type | Meaning |
| --- | --- | --- |
| `ipcam.ipcam_dev` | string | Camera device present (`"1"` / `"0"`) |
| `ipcam.ipcam_record` | string | Recording enable (`"enable"` / `"disable"`) |
| `ipcam.timelapse` | string | Timelapse enable |
| `ipcam.resolution` | string | e.g. `"1080p"` / `"720p"` |
| `ipcam.rtsp_url` | string | LAN RTSP(S) URL when live |
| `ipcam.liveview_preview` | bool | Liveview preview supported / enabled |
| `ipcam.cap_pic_enable` | string | Snapshot capture enable (`"invalid"` / …) |
| `ipcam.mode_bits` | int | Camera mode bitfield — **partially unknown** |
| `ipcam.bs_state` | int | **Unknown** (bitstream / bind state?) |
| `ipcam.laser_preview_res` | int | Laser / lidar preview resolution code |
| `ipcam.agora_service` | string | `"enable"` / `"disable"` — Agora cloud video |
| `ipcam.tutk_server` | string | `"enable"` / `"disable"` — TUTK |
| `ipcam.brtc_service` | string | `"enable"` / `"disable"` — BRTC / `:6000` media |
| `ipcam.tl_store_path_type` | int | Timelapse storage path type (internal vs external) |
| `ipcam.tl_store_hpd_type` | int | Timelapse hotplug / disk type |
| `ipcam.tl_internal_free_kb` / `tl_internal_total_kb` | int | Internal timelapse storage KB |
| `ipcam.tl_external_free_kb` / `tl_external_total_kb` | int | External (USB) timelapse storage KB |

Also mirrored under `device.cam.tl_*` — [§12.1.4](12.01.04-fields-device.md).

Studio also parses these when present (not in the P2S full-frame snapshot used for this catalogue): `ipcam.resolution_supported[]`, `ipcam.liveview.local` / `.remote`, `ipcam.file.local` / `.remote` / `.model_download`, `ipcam.virtual_camera`.

#### `xcam` / `xcam_status`

| Field | Type | Meaning |
| --- | --- | --- |
| `xcam_status` | string | Overall xcam status code (stringified int) |
| `xcam.cfg` | int | Packed enable + sensitivity bits — decode in [§12.1](12.01-status.md#printxcamcfg-integer-decimal-not-hex) (legacy non-NP); on NP printers AI toggles may live in `cfg` / booleans instead |
| `xcam.spaghetti_detector` | bool | Spaghetti detection enabled |
| `xcam.printing_monitor` | bool | AI printing monitor enabled |
| `xcam.print_halt` | bool | Halt print on AI event |
| `xcam.first_layer_inspector` | bool | First-layer inspection |
| `xcam.buildplate_marker_detector` | bool | Buildplate marker detection |
| `xcam.halt_print_sensitivity` | string | `"low"` / `"medium"` / `"high"` |
| `xcam.allow_skip_parts` | bool | Allow skipping parts on AI events |

Hub: [§12.1](12.01-status.md).
