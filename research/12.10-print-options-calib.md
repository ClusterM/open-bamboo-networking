### 12.10. Machine calibration & `print_option`

Studio-built machine calibration and `print_option` toggles. Plugin forwards only. Envelope: [§6.2](06.02-mqtt.md). Related: PA [§12.8](12.08-pa-calibration.md), flow [§12.9](12.09-flow-calibration.md).

#### `print.calibration`

Start selected built-in calibration routines. Builder: [`DeviceManager.cpp:1884`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/DeviceManager.cpp#L1884).

| Field | Type | Notes |
| --- | --- | --- |
| `command` | string | `"calibration"` |
| `sequence_id` | string | Studio 20000–29999 |
| `option` | int bitmask | bits 0…6: xcam, bed-level, vibration, motor-noise, nozzle, bed, clump-position |

```json
{
  "print": {
    "sequence_id": "20000",
    "command": "calibration",
    "option": 15
  }
}
```

**Response.** No command-specific ack parser; progress / completion is consumed from later `print.push_status` ([§12.1](12.01-status.md)). **Not live-probed** (starts hardware routines).

#### `print.gcode_file`

Legacy X1-era path: run a fixed on-printer calibration G-code file. Builder: [`DeviceManager.cpp:1878`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/DeviceManager.cpp#L1878).

| Field | Type | Notes |
| --- | --- | --- |
| `command` | string | `"gcode_file"` |
| `sequence_id` | string | Studio 20000–29999 |
| `param` | string | Fixed path `/usr/etc/print/auto_cali_for_user.gcode` |

```json
{
  "print": {
    "sequence_id": "20000",
    "command": "gcode_file",
    "param": "/usr/etc/print/auto_cali_for_user.gcode"
  }
}
```

**Response.** No command-specific parser; generic `err_code` handling possible. Prefer `print.calibration` on modern firmwares. **Not live-probed.**

#### `print.print_option`

Change one print option; each builder emits only its relevant field(s).

| name | type/values | notes |
|---|---|---|
| `sequence_id` | string | Studio counter; example fixed to `"20000"` |
| `command` | string | constant `"print_option"` |
| `option` | int | auto-recovery bit/value |
| `auto_recovery` | bool | step-loss recovery |
| `auto_switch_filament` | bool | automatic AMS refill |
| `air_print_detect` | bool | air-print detection |
| `nozzle_blob_detect` | bool | legacy blob detection |
| `sound_enable` | bool | prompt sound |
| `filament_tangle_detect` | bool | tangle detection |
| `air_purification` | int | 0 off, 1 inside, 2 outside |
| `nozzle_blob_detect_v2` | int | 0 off, 1 on, 2 auto |

**Reply parsing:** `[`src/slic3r/GUI/DeviceCore/DevPrintOptions.cpp:8-289`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/DeviceCore/DevPrintOptions.cpp#L8-L289)`, dispatched at `DeviceManager.cpp:3596`.

```json
{
  "print": {
    "sequence_id": "20000",
    "command": "print_option",
    "option": 1,
    "auto_recovery": true
  }
}
```
