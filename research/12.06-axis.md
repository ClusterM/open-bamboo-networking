### 12.6. Axis / homing

Studio-built axis MQTT commands (`back_to_center`, `xyz_ctrl`). Plugin forwards only. Envelope: [§6.2](06.02-mqtt.md). Arbitrary G-code passthrough is a separate surface: [§12.15](12.15-gcode-line.md). Hub: [§12](12-mqtt.md).

Capability gates (from `push_status`): `fun` bit 32 MQTT homing, bit 38 MQTT axis jog — [§12.1](12.01-status.md). When those bits are clear Studio falls back to `gcode_line` (G28 / jog G-code).

**Not live-probed** (moves the machine). Request shapes from Studio builders; replies are typically reflected in the next `push_status` home flags rather than a dedicated ack body.

#### `print.back_to_center`

Home through the structured MQTT protocol. Builder: [`DevAxisCtrl.cpp:13`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/DeviceCore/DevAxisCtrl.cpp#L13).

| Field | Type | Notes |
| --- | --- | --- |
| `command` | string | `"back_to_center"` |
| `sequence_id` | string | Studio 20000–29999 |

```json
{
  "print": {
    "sequence_id": "20000",
    "command": "back_to_center"
  }
}
```

**Response.** No dedicated ack parser; Studio watches axis home bits in `push_status` ([`DevAxis.cpp:9-12`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/DeviceCore/DevAxis.cpp#L9-L12)).

#### `print.xyz_ctrl`

Jog an axis. Builder: [`DevAxisCtrl.cpp:32`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/DeviceCore/DevAxisCtrl.cpp#L32).

| Field | Type | Notes |
| --- | --- | --- |
| `command` | string | `"xyz_ctrl"` |
| `sequence_id` | string | Studio 20000–29999 |
| `axis` | string | `X`, `Y`, or `Z` |
| `dir` | int | `-1` or `1` (after kinematic inversion) |
| `mode` | int | `1` when requested distance ≥ 10; else `0` |

```json
{
  "print": {
    "sequence_id": "20000",
    "command": "xyz_ctrl",
    "axis": "X",
    "dir": 1,
    "mode": 1
  }
}
```

**Response.** Same as homing — state via `push_status`, not a structured jog ack.

Hub: [§12](12-mqtt.md).
