### 12.1.6. `push_status` fields — network / upgrade / errors / misc

Leaf catalogue for network, OTA, HMS/errors, care, `3D`, and `mapping` in `print.push_status`. Upgrade commands: [§12.13](12.13-upgrade.md). Mapping / nozzle rack: [§12.14](12.14-nozzle-rack.md).

Catalogue from a full (`msg: 0`) **P2S** frame.

#### Network / storage

| Field | Type | Meaning |
| --- | --- | --- |
| `wifi_signal` | string | RSSI text, e.g. `"-49dBm"` — Studio |
| `sdcard` | bool | SD / external storage present (legacy; also `home_flag` / `aux` bits) |
| `online.ahb` | bool | AHB / AP board online |
| `online.version` | int | Online protocol / structure version |
| `online.rfid` | bool | RFID reader online (Studio; may be absent on NP / P2S) |
| `net.conf` | int | Network config flags — **unknown** bit layout |
| `net.info[]` | array | Interface list |
| `net.info[].ip` | int | IPv4 as integer (host/network byte order — treat carefully) |
| `net.info[].mask` | int | Netmask as integer |

#### `upgrade_state` / force upgrade

| Field | Type | Meaning |
| --- | --- | --- |
| `force_upgrade` | bool | Top-level force-upgrade flag |
| `upgrade_state.status` | string | e.g. `"IDLE"` |
| `upgrade_state.progress` | string | Progress percent as string |
| `upgrade_state.message` | string | Status / error message |
| `upgrade_state.module` | string | Module being upgraded |
| `upgrade_state.sn` | string | Device serial |
| `upgrade_state.sequence_id` | int | Upgrade sequence |
| `upgrade_state.err_code` | int | Upgrade error |
| `upgrade_state.consistency_request` | bool | Consistency confirm needed — [§12.13](12.13-upgrade.md) |
| `upgrade_state.force_upgrade` | bool | Force flag inside object |
| `upgrade_state.dis_state` | int | Display / dialog state |
| `upgrade_state.new_version_state` | int | New-version availability state |
| `upgrade_state.ota_new_version_number` | string | OTA new version |
| `upgrade_state.ams_new_version_number` | string | AMS new version |
| `upgrade_state.ahb_new_version_number` | string | AHB new version |
| `upgrade_state.ext_new_version_number` | string | Extension module new version |
| `upgrade_state.lower_limit` | string | Minimum allowed version |
| `upgrade_state.idx` / `idx2` | int | Version list indices / tokens — **partially unknown** |

#### Errors / HMS

| Field | Type | Meaning |
| --- | --- | --- |
| `print_error` | int | Active print error — Studio |
| `mc_print_error_code` | string | MC error code |
| `mc_err` | int | MC error int |
| `ap_err` | int | AP / application-processor error |
| `fail_reason` | string | Failure reason |
| `err` | string | Error string / code |
| `err2.err_code` | string | Structured error code |
| `err2.img_id` | string | Error illustration id for UI |
| `hms` | array | HMS error list for Studio dialogs |
| `hms[].code` | int | HMS code |
| `hms[].attr` | int | HMS attributes / module packing |
| `hms[].ts_boot` | int | Timestamp since boot |
| `hms[].ts_unix` | string | Wall-clock stamp string |

HMS `attr` / `code` bit packing and long-code layout: [§12.1](12.01-status.md#hms-health-management-system-bit-packing).

#### `care` (maintenance)

| Field | Type | Meaning |
| --- | --- | --- |
| `care[]` | array | Care / maintenance counters |
| `care[].id` | string | Counter id (e.g. `"ss"`, `"ls"`) — **unknown** expansion |
| `care[].info` | string | Hex / packed counter value — **unknown** units |

#### `3D` side-channel

| Field | Type | Meaning |
| --- | --- | --- |
| `3D.layer_num` | int | Layer (may lag / differ from top-level `layer_num`) |
| `3D.total_layer_num` | int | Total layers |
| `3D.print_cali_option` | int | Print calibration option flags — **unknown** |
| `3D.ventobox.enable` | bool | Ventobox accessory enabled |
| `3D.ventobox.speed` | int | Ventobox speed |
| `3D.ventobox.visable` | bool | UI visibility (firmware spelling) |

#### `mapping`

| Field | Type | Meaning |
| --- | --- | --- |
| `mapping` | array | Nozzle↔filament / AMS mapping payload — Studio `print_job_filament_mapping`; see [§12.14](12.14-nozzle-rack.md). On single-extruder P2S often a flat int array (e.g. `[0]`). |

Hub: [§12.1](12.01-status.md).
