### 8.13. Tracking / telemetry

Privacy-gated analytics surface: an opaque property store plus an event firehose. Studio drives it heavily after the user opts into improvement / privacy tracking; return codes are almost never checked. A compatible plugin that returns `0` from every symbol (and clears `track_get_property` to empty / `"0"`) is functionally indistinguishable for Studio’s own UI paths — stock additionally batches encrypted uploads to the cloud.

Studio resolves the exports via `dlsym` ([NetworkAgent.cpp:380-385](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/Utils/NetworkAgent.cpp#L380-L385)). Typedefs: [NetworkAgent.hpp:105-110](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/Utils/NetworkAgent.hpp#L105-L110). No track-specific `BAMBU_NETWORK_ERR_*` codes.

Neighbors: privacy consent HTTP ([§8.10.11](08.10-http.md#81011-bambu_network_report_consent)); HTTP hosts ([§6.6](06.06-cloud-rest.md)). **Not** this ABI: WebView GA / Clarity / `event.bblmw.com` / Sentry `perf.bblmw.com`; Studio log encryption also calls `GET …/analysis-st/tag/` ([GUI_App.cpp:2495-2507](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/GUI_App.cpp#L2495-L2507)) outside the track symbols.

#### 8.13.1. Common contract

**Consent gate.** Studio only enables tracking when `app_config["firstguide"]["privacyuse"] == "true"` ([`GUI_App::check_track_enable`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/GUI_App.cpp#L5388-L5415)). Called after agent bring-up when already logged in, and again from `on_user_login`. Opt-out in Preferences clears the flag and calls `track_enable(false)` + `track_remove_files` ([Preferences.cpp:831-839](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/Preferences.cpp#L831-L839)); re-enable goes back through `check_track_enable` (not a bare `track_enable(true)` from Preferences).

**NetworkAgent wrapper gates** ([NetworkAgent.cpp:1635-1712](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/Utils/NetworkAgent.cpp#L1635-L1712)):

| Symbol | Called when |
| --- | --- |
| `track_enable` | Always (also sets local `enable_track`) |
| `track_remove_files` | Always (no `enable_track` check) |
| `track_header` / `track_update_property` / `track_get_property` | Only if `enable_track` |
| `track_event` | Only if `enable_track` **and** `is_user_login()` |

**Lifecycle.**

```text
privacy on + logged in:
  track_enable(true) → track_header({ver,os,name,uuid}) → track_event("studio_launch", …)
  … update_property / track_event during session …
  shutdown: track_get_property × N → aggregate track_event(key_func|…) → track_enable(false)

privacy off:
  track_remove_files()   (check_track_enable else-branch)
  or track_enable(false) + track_remove_files() (Preferences toggle)
```

Studio also keeps a local privacy-history file under `data_dir()/track/history.txt` ([GUI_App.cpp:5327-5333](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/GUI_App.cpp#L5327-L5333)) — separate from the plugin’s buffered event files.

**Stock upload wire** (MITM stock `02.08.01.53`, cold start `stock_track_cold.mitm` / earlier hybrid dumps; UA `bambu_network_agent/…`):

1. `GET /v1/analysis-st/tag/?UID=<slicer_or_user_uid>` (Bearer) → JSON `{ "tag", "secret", "iv" }` (AES material; occasionally HTTP 400 `"resource is out"` then retry).
2. `GET /v1/iot-service/api/user/upload?event_track/slicer=<filename>.zip.enc` (Bearer) → presigned S3 URL; `urls[].type = "event_track/slicer"`.
3. `PUT <presigned S3 URL>` — body is encrypted (not a raw ZIP; observed ~0.5–1 KiB payloads, no `Authorization` header on the PUT).

Filename pattern observed:

```text
<user_id>_track_<plugin_ver>_<yyyymmddHHMMSS>_<tag>.zip.enc
```

Uploads are **batched** (not one HTTPS call per `track_event`).

**TODO**: need unpack of `.zip.enc` (how `secret`/`iv`/`tag` fold into ciphertext) and whether `track_header` fields appear inside the blob.

**Return convention.** `int`; Studio expects `0`. No dedicated track error family in [§8.16](08.16-errors.md).


#### 8.13.2. `bambu_network_track_enable`

**Parameters.**

| Name | Type | Meaning |
| --- | --- | --- |
| `agent` | `void*` | Opaque agent from `create_agent`. |
| `enable` | `bool` | `true` to arm tracking; `false` to disarm. |

**Purpose.** Turn the plugin’s tracking subsystem on or off; Studio also mirrors the flag in `NetworkAgent::enable_track`.

**Studio.** [`check_track_enable`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/GUI_App.cpp#L5400) (`true`); Preferences privacy off ([Preferences.cpp:837](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/Preferences.cpp#L837)); MainFrame shutdown ([MainFrame.cpp:1127](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/MainFrame.cpp#L1127)) (`false`). Wrapper: [NetworkAgent.cpp:1635-1644](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/Utils/NetworkAgent.cpp#L1635-L1644).

**Plugin behaviour.** Persist enable state. When `false`, stop accepting new events / properties for upload (Studio already gates most calls). No dedicated HTTPS observed for enable itself — cloud activity follows later `track_event` / flush. Evidence: Studio source + MITM (upload only after enabled session).

**Return.** `0` on success.
