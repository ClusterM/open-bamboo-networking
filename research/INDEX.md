# Bambu Studio Network Plugin — research index

Reverse-engineering reference for how Bambu Studio integrates with its proprietary **Network Plugin** (`bambu_networking`) and `libBambuSource`: download/install, validation, printer channels, C ABI, cloud HTTP transport, security, print flows, MQTT wire formats, and camera/file-browser CTRL.

Derived from BambuStudio / OrcaSlicer sources, MITM of the stock plugin, and cross-ABI matrix runs — not from binary disassembly. Open-plugin implementation status lives in [STATUS.md](../STATUS.md), not here.
