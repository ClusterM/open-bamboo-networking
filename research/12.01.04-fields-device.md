### 12.1.4. `push_status` fields — `device.*` hardware tree

Leaf catalogue for NP-style nested `print.device` in `print.push_status` (P2S). Flat legacy temps/fans: [§12.1.2](12.01.02-fields-thermal-fans.md). Studio: `parse_new_info` / `DevFan` / `DevBed` / `DevNozzleSystem` / `ExtderSystemParser` / `DevExtensionToolParser`.

Catalogue from a full (`msg: 0`) **P2S** frame. Many numeric `temp` / `info` fields are **packed integers** (not plain °C) — treat encoding as **unknown** unless noted.

#### Root

| Field | Type | Meaning |
| --- | --- | --- |
| `device.type` | int | Device / structure type code |
| `device.bed_temp` | int | Packed bed temperature word (duplicates `device.bed.info.temp`) |
| `device.fan` | int | Fan summary / packed state — **unknown** vs flat fan speeds |
| `device.holder` | null/object | Tool / accessory holder — often `null` |

#### `device.bed`

| Field | Type | Meaning |
| --- | --- | --- |
| `device.bed.state` | int | Bed heater / presence state |
| `device.bed.info.temp` | int | Packed bed temperature |

#### `device.ctc` (chamber / enclosure)

| Field | Type | Meaning |
| --- | --- | --- |
| `device.ctc.state` | int | Chamber control state |
| `device.ctc.info.temp` | int | Chamber temperature (°C-class on observed P2S) |

#### `device.extruder`

| Field | Type | Meaning |
| --- | --- | --- |
| `device.extruder.state` | int | Extruder system state |
| `device.extruder.info[]` | array | Per-extruder records |
| `device.extruder.info[].id` | int | Extruder id |
| `device.extruder.info[].temp` | int | Nozzle / hotend temperature (may be plain °C) |
| `device.extruder.info[].stat` | int | Extruder status flags |
| `device.extruder.info[].info` | int | Packed info word |
| `device.extruder.info[].filam_bak` | array | Filament backup mapping |
| `device.extruder.info[].hnow` / `hpre` / `htar` | int | **Unknown** (hub / AMS head indices?) |
| `device.extruder.info[].snow` / `spre` / `star` | int | Slot now / previous / target (AMS slot addressing) |
| `device.extruder.info[].z_bias` | float | Z offset bias |

#### `device.nozzle`

| Field | Type | Meaning |
| --- | --- | --- |
| `device.nozzle.exist` | int | Nozzle present bitmask / flag |
| `device.nozzle.state` | int | Nozzle system state |
| `device.nozzle.src_id` / `tar_id` | int | Source / target nozzle ids (rack) |
| `device.nozzle.info[]` | array | Per-nozzle records |
| `device.nozzle.info[].id` | int | Nozzle index |
| `device.nozzle.info[].diameter` | float | Diameter mm |
| `device.nozzle.info[].type` | string | Type string (`HS01`, …) |
| `device.nozzle.info[].sn` | string | Serial |
| `device.nozzle.info[].stat` | int | Status |
| `device.nozzle.info[].wear` | float | Wear metric |
| `device.nozzle.info[].tm` | int | **Unknown** timestamp / counter |
| `device.nozzle.info[].p_t` | int | **Unknown** |
| `device.nozzle.info[].fila_id` | string | Bound filament id |
| `device.nozzle.info[].color_m` | string | Colour marker |

#### `device.airduct`

| Field | Type | Meaning |
| --- | --- | --- |
| `device.airduct.version` | int | Schema version |
| `device.airduct.modeCur` | int | Current airduct mode |
| `device.airduct.modeFunc` | int | Mode function |
| `device.airduct.modeVisable` | int | Visible modes bitmask (firmware spelling) |
| `device.airduct.subMode` / `subFunc` / `subVisable` | int | Sub-mode fields |
| `device.airduct.modeList[]` | array | Mode definitions |
| `device.airduct.modeList[].modeId` | int | Mode id |
| `device.airduct.modeList[].ctrl[]` | array\<int\> | Part ids controlled in this mode |
| `device.airduct.modeList[].off[]` | array\<int\> | Part ids forced off |
| `device.airduct.parts[]` | array | Duct / fan parts |
| `device.airduct.parts[].id` | int | Part id |
| `device.airduct.parts[].func` | int | Function code |
| `device.airduct.parts[].state` / `tar_state` | int | Current / target speed or state |
| `device.airduct.parts[].range` | int | Allowed range (packed) |
