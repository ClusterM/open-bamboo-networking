### 12.1.4. `push_status` fields — `device.*` hardware tree

Leaf catalogue for NP-style nested `print.device` in `print.push_status` (P2S). Flat legacy temps/fans: [§12.1.2](12.01.02-fields-thermal-fans.md). Studio: `parse_new_info` / `DevFan` / `DevBed` / `DevNozzleSystem` / `ExtderSystemParser` / `DevExtensionToolParser`.

Catalogue from a full (`msg: 0`) **P2S** frame, extended with an **X2D** (`01.02.00.00`, two extruders) `pushall`. Many numeric `temp` / `info` fields are **packed integers** (not plain °C) — treat encoding as **unknown** unless noted.

#### Root

| Field | Type | Meaning |
| --- | --- | --- |
| `device.type` | int | Device / structure type code |
| `device.bed_temp` | int | Packed bed temperature word (duplicates `device.bed.info.temp`) |
| `device.fan` | int | Fan summary / packed state — **unknown** vs flat fan speeds |
| `device.holder` | null/object | Tool / accessory holder — often `null` |

| Field | Type | Meaning |

#### `device.extruder`

| Field | Type | Meaning |
| --- | --- | --- |
| `device.extruder.state` | int | Packed system word (Studio `ExtderSystemParser::ParseV2_0`): bits 0–3 extruder count, 4–7 current extruder, 8–11 target extruder, 12–14 switch state, 15–18 extruder currently loading, bit 19 busy loading |
| `device.extruder.info[]` | array | Per-extruder records (one on the P2S, two on the X2D) |
| `device.extruder.info[].id` | int | Extruder id (`0` = main / right, `1` = deputy / left) |
| `device.extruder.info[].temp` | int | Packed: bits 0–15 current °C, 16–31 target °C |
| `device.extruder.info[].stat` | int | Bits 0–15 AMS / filament-change step, 16–31 RFID state |
| `device.extruder.info[].info` | int | Bit 1 filament in the extruder, bit 2 filament in the buffer, bit 3 nozzle mounted |
| `device.extruder.info[].filam_bak` | array | Filament backup mapping |
| `device.extruder.info[].hnow` / `hpre` / `htar` | int | Nozzle id now / previous / target (Studio reads `hnow` as the extruder's current nozzle) |
| `device.extruder.info[].snow` / `spre` / `star` | int | Slot now / previous / target: bits 8–15 AMS id, bits 0–7 slot; `0xffff` = none |
| `device.extruder.info[].z_bias` | float | Z offset bias |

X2D example (printing PETG from AMS 0 slot 1 on the left extruder): `state` `33042` = `0x8112` → two extruders, current `1`, target `1`, loading `1`; extruder `1` `temp` `0x00ff00ff` (255/255 °C), `info` `1102` (filament, buffer, nozzle), `snow` `1` (AMS 0 slot 1), `hnow` `1`; idle extruder `0` `temp` `0x00190032` (50 °C, target 25), `info` `1272` (nozzle only), `snow` `0xffff`.

#### `device.fila_switch` (Filament Track Switch)

Present on the X2D with the Filament Track Switch accessory (`print.aux` bit 29 = installed; Studio `DevFilaSwitch`). It lets both AMS units feed either extruder.

| Field | Type | Meaning |
| --- | --- | --- |
| `device.fila_switch.in` | array\<int\>[2] | Slot at input B / input A: bits 8–15 AMS id, 0–7 slot; `-1` = empty |
| `device.fila_switch.out` | array\<int\>[2] | Extruder at output B / output A; `0xE` = none |
| `device.fila_switch.stat` | int | Calibration status |
| `device.fila_switch.info` | int | Bit 0: filament present at the inputs |

X2D: `in` `[-1, 1]` (input A holds AMS 0 slot 1), `out` `[0, 1]` (output B → extruder 0, output A → extruder 1). The AMS units then report extruder `0xE` in their `info` word and name the switch input they are wired to ([§12.1.3](12.01.03-fields-ams.md)).
