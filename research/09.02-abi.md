### 9.2. C ABI surface (`Bambu_*`)

Pure-C tunnel API exported from `libBambuSource` / `BambuSource.dll`. Header: [BambuTunnel.h](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/Printer/BambuTunnel.h) (pin `12f17b06`). Studio uses the **dlopen** path (`#define BAMBU_DYNAMIC`): function pointers live in `BambuLib`, filled by `StaticBambuLib::get` ([PrinterFileSystem.cpp:1840-1879](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/Printer/PrinterFileSystem.cpp#L1840-L1879)). `PrinterFileSystem` and current `wxMediaCtrl3` inherit / embed that table.

Neighbors: load order ([§9.1](09.01-loading.md)); URL grammar ([§9.3](09.03-urls.md)); camera back-ends ([§9.4](09.04-camera-backends.md)); CTRL JSON ([§9.5](09.05-ctrl.md)); `:6000` wire ([§6.4](06.04-port-6000.md)); hub ([§9](09-abi-bambusource.md)).

#### 9.2.1. Common contract

**Wiring.** `StaticBambuLib` `GET_FUNC`s ([PrinterFileSystem.cpp:1856-1871](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/Printer/PrinterFileSystem.cpp#L1856-L1871)): `Create`, `Open`, `StartStream`, `StartStreamEx`, `GetStreamCount`, `GetStreamInfo`, `SendMessage`, `ReadSample`, `Close`, `Destroy`, `SetLogger`, `SetStreamInfoCallback`, `SetTrackReporter`, `GetSessionStat`, `FreeLogMsg`, `Deinit`. If `Bambu_Create` is missing → `Fake_Bambu_Create` returns `−2` (“library missing”). Header-only relative to this loader (still exported by stock dylibs): `Init`, `GetDuration`, `Seek`, `RecvMessage`, `GetLastErrorMsg`.

**Types** ([BambuTunnel.h:36-136](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/Printer/BambuTunnel.h#L36-L136)):

| Type | Role |
| --- | --- |
| `Bambu_Tunnel` | Opaque `void*` handle |
| `tchar` | `wchar_t` on Windows, `char` elsewhere — logger / `FreeLogMsg` |
| `Logger` | `void(*)(void* ctx, int level, tchar const* msg)` |
| `Bambu_Sample` | `{ itrack, size, flags, buffer, decode_time }` — one media AU or one CTRL envelope |
| `Bambu_StreamInfo` | Track type / subtype / format union + `format_buffer` |
| `Bambu_SessionStat` | Session metrics struct (optional API) |
| `PlayerEventC` / `TrackReporter` | LiveView analytics hook (optional API) |

**`Bambu_Error`:**

| Value | Enumerator | Meaning |
| ---: | --- | --- |
| `0` | `Bambu_success` | OK / sample ready |
| `1` | `Bambu_stream_end` | End of stream |
| `2` | `Bambu_would_block` | Not ready — poll again |
| `3` | `Bambu_buffer_limit` | Caller buffer too small |

Negative returns are **fatal**: Studio calls `Close` + `Destroy` and reconnects ([§9 hub](09-abi-bambusource.md#lifetime-error-propagation-and-reconnect)).

**Consumers.**

| Path | Lifecycle sketch |
| --- | --- |
| Camera (`wxMediaCtrl3` / `gstbambusrc`) | `Create(url)` → `SetLogger` → `Open` → `StartStream(true)` → `GetStreamInfo` → loop `ReadSample` |
| File browser (`PrinterFileSystem`) | `Create(url)` → `Open` → `StartStreamEx(0x3001)` → `SendMessage` / `ReadSample` JSON ([§9.5](09.05-ctrl.md)) |

**ABI note.** `extern "C"` with C structs by pointer/value — match Studio’s C ABI / calling convention. Safer than `bambu_networking` (no `std::*`), but `tchar` width still matters.


#### 9.2.2. `Bambu_Init`

**Parameters.** None.

**Purpose.** One-shot global library init.

**Studio.** Declared; not in the usual `StaticBambuLib` bring-up path. Observed shipping libs often no-op.

**Plugin behaviour.** Idempotent init if required; otherwise return success.

**Return.** `0` on success; negative on failure.


#### 9.2.3. `Bambu_Deinit`

**Parameters.** None.

**Purpose.** Global teardown.

**Studio.** `StaticBambuLib::release()` on agent reset.

**Plugin behaviour.** Release global resources; safe if never inited.

**Return.** `void`.


#### 9.2.4. `Bambu_Create`

**Parameters.**

| Name | Type | Meaning |
| --- | --- | --- |
| `tunnel` | `Bambu_Tunnel*` | out: opaque handle |
| `path` | `char const*` | URL from Studio ([§9.3](09.03-urls.md)) |

**Purpose.** Allocate a tunnel bound to `path` (not necessarily connected).

**Studio.** Every camera / file-browser session. Missing export → `Fake_Bambu_Create` → `−2`.

**Plugin behaviour.** Parse URL; allocate handle. Connection happens in `Open` / `StartStream*`.

**Return.** `0` and non-null `*tunnel` on success; `−2` if library stub; other negatives fatal.


#### 9.2.5. `Bambu_Destroy`

**Parameters.**

| Name | Type | Meaning |
| --- | --- | --- |
| `tunnel` | `Bambu_Tunnel` | Handle from `Create` |

**Purpose.** Free the tunnel after `Close`.

**Studio.** End of tab / reconnect teardown.

**Plugin behaviour.** Free all resources; must be safe after `Close` even if a reader was recently in `ReadSample`.

**Return.** `void`.

#### 9.2.9. `Bambu_Open`

**Parameters.**

| Name | Type | Meaning |
| --- | --- | --- |
| `tunnel` | `Bambu_Tunnel` | Tunnel handle |

**Purpose.** Begin transport connect (TLS `:6000`, RTSP(S), TUTK, … per URL).

**Studio.** Polled until not `would_block` (file browser / camera).

**Plugin behaviour.** For LAN CTRL / MJPEG file URLs: TLS connect ([§6.4](06.04-port-6000.md)); CTRL login/setup follows in `StartStreamEx`. May return `Bambu_would_block` while connecting.

**Return.** `Bambu_success`, `Bambu_would_block`, or negative fatal.

**Studio.** Tab close / fatal error / reconnect.

#### 9.2.12. `Bambu_StartStreamEx`

**Parameters.**

| Name | Type | Meaning |
| --- | --- | --- |
| `tunnel` | `Bambu_Tunnel` | Tunnel handle |
| `type` | `int` | Stream / mode selector. File browser: `CTRL_TYPE = 0x3001` ([PrinterFileSystem.h:32](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/Printer/PrinterFileSystem.h#L32)). |

**Purpose.** Preferred start; `0x3001` switches the tunnel to CTRL JSON-RPC ([§9.5](09.05-ctrl.md)).

**Studio.** File browser polls until success / timeout (~5 s).

**Return.** `Bambu_success`, `Bambu_would_block`, or negative.

**Parameters.**

| Name | Type | Meaning |
