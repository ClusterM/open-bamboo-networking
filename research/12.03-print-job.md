### 12.3. Print job control & HMS

Studio-built `print.*` job-control and HMS MQTT commands. Plugin forwards only. Envelope: [§6.2](06.02-mqtt.md).

#### `print.clean_print_error`

Clear a print error for a subtask.

| name | type/values | notes |
|---|---|---|
| `sequence_id` | string | Studio counter; example fixed to `"20000"` |
| `command` | string | constant `"clean_print_error"` |
| `subtask_id` | string | subtask ID |
| `print_error` | int | printer error code |

**Reply parsing:** No command-specific parser; generic `err_code` handling: `[`src/slic3r/GUI/DeviceManager.cpp:2983-2991`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/DeviceManager.cpp#L2983-L2991)`.

```json
{
  "print": {
    "sequence_id": "20000",
    "command": "clean_print_error",
    "subtask_id": "12345",
    "print_error": 0
  }
}
```
