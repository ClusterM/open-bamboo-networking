### 12.1.2. `push_status` fields — temperatures / fans / lights

Leaf catalogue for thermal, fan, and lighting telemetry in `print.push_status`. Commands: [§12.4](12.04-temps-extruder.md), [§12.5](12.05-fans.md), [§12.2](12.02-system.md) `ledctrl`.

Catalogue from a full (`msg: 0`) **P2S** frame; other models may omit keys. Nested NP hardware temps also under `device.*` — [§12.1.4](12.01.04-fields-device.md).

#### Bed / nozzle (legacy flat fields)

| Field | Type | Meaning |
| --- | --- | --- |
| `bed_temper` | number | Bed actual °C — Studio |
| `bed_target_temper` | number | Bed target °C — Studio |
| `nozzle_temper` | number | Nozzle actual °C — Studio |
| `nozzle_target_temper` | number | Nozzle target °C — Studio |
| `nozzle_diameter` | string | Nozzle diameter, e.g. `"0.4"` — Studio |
| `nozzle_type` | string | Nozzle type / SKU, e.g. `"HS01"` — Studio |
| `info.temp` | int | Extra / packed temp channel — **unknown** encoding (raw int on P2S) |

#### Fans

| Field | Type | Meaning |
| --- | --- | --- |
| `cooling_fan_speed` | string | Part-cooling fan speed (stringified) |
| `big_fan1_speed` | string | Auxiliary / chamber fan 1 speed |
| `big_fan2_speed` | string | Auxiliary / chamber fan 2 speed |
| `heatbreak_fan_speed` | string | Heatbreak fan speed |
| `fan_gear` | int | Packed fan gear / mode bitfield — **partially unknown** |
| `aux_part_fan` | bool | Aux part-cooling fan present / enabled |

NP nested fan / duct: `device.fan`, `device.airduct` — [§12.1.4](12.01.04-fields-device.md).

#### Lights

| Field | Type | Meaning |
| --- | --- | --- |
| `lights_report` | array | Light nodes currently reported |
| `lights_report[].node` | string | Node name, e.g. `"chamber_light"`, `"work_light"` |
| `lights_report[].mode` | string | `"on"` / `"off"` / `"flashing"` / … |

Pairs with `system.ledctrl` — [§12.2](12.02-system.md). Chamber light also mirrored in NP `cfg` bit 7 — [§12.1 capability flags](12.01-status.md).

Hub: [§12.1](12.01-status.md).
