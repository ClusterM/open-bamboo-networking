### 12.2. System / lights / door / cache / UI

Studio-built `system.*` MQTT commands. Plugin forwards only. Envelope: [§6.2](06.02-mqtt.md). Hub: [§12](12-mqtt.md).

#### `system.get_access_code`

Request the current LAN access code. Builder: [`DeviceManager.cpp:1288-1293`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/DeviceManager.cpp#L1288-L1293). Parser: [`:2600-2607`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/DeviceManager.cpp#L2600-L2607).

```json
{
  "system": {
    "sequence_id": "20000",
    "command": "get_access_code"
  }
}
```

**Response (live P2S):**

```json
{
  "system": {
    "command": "get_access_code",
    "sequence_id": "20003",
    "result": "success",
    "access_code": "<8-char>"
  }
}
```

#### `system.uiop`

Close a printer-error dialog. Builder: [`DeviceManager.cpp:1357-1372`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/DeviceManager.cpp#L1357-L1372).

| Field | Type | Notes |
| --- | --- | --- |
| `name` | string | `"print_error"` |
| `action` | string | `"close"` |
| `source` | int | `1` = Studio |
| `type` | string | `"dialog"` |
| `err` | string | 8-digit uppercase hex error |

```json
{
  "system": {
    "sequence_id": "20000",
    "command": "uiop",
    "name": "print_error",
    "action": "close",
    "source": 1,
    "type": "dialog",
    "err": "03008011"
  }
}
```

#### `system.ledctrl`

Control chamber-light node(s), including flash timing. Builder: [`DevLampCtrl.cpp`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/DeviceCore/DevLampCtrl.cpp). State often via `push_status.lights_report`.

| Field | Type | Notes |
| --- | --- | --- |
| `led_node` | string | `chamber_light` or `chamber_light2` |
| `led_mode` | string | `on`, `off`, `flashing`, … |
| `led_on_time` / `led_off_time` / `loop_times` / `interval_time` | int | Flash timing |

```json
{
  "system": {
    "sequence_id": "20000",
    "command": "ledctrl",
    "led_node": "chamber_light",
    "led_mode": "on",
    "led_on_time": 500,
    "led_off_time": 500,
    "loop_times": 1,
    "interval_time": 0
  }
}
```

#### `system.set_door_stat`

Configure the door-open reaction. Builder: [`DeviceManager.cpp:4842`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/DeviceManager.cpp#L4842).

| Field | Type | Notes |
| --- | --- | --- |
| `config` | int | `0` disabled, `1` warning, `2` pause |

```json
{
  "system": {
    "sequence_id": "20000",
    "command": "set_door_stat",
    "config": 2
  }
}
```

