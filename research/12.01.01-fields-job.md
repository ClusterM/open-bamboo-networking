### 12.1.1. `push_status` fields — job / progress / stages

Leaf catalogue for inbound `print.push_status` job-related keys. Hub / envelope / capability bits: [§12.1](12.01-status.md). Control commands: [§12.3](12.03-print-job.md).

Catalogue from a full (`msg: 0`) **P2S** frame; other models may omit keys. Diff frames (`msg: 1`) omit unchanged fields. Studio pin: `12f17b06f4f537f9c03162d08bb70cf733c42839`.

#### High-level state / progress

| Field | Type | Meaning |
| --- | --- | --- |
| `gcode_state` | string | High-level job state: `IDLE`, `RUNNING`, `PAUSE`, `FINISH`, `FAILED`, … Studio: `DeviceManager.cpp` |
| `state` | int | **Unknown** integer state code (observed `4` while `gcode_state` was `RUNNING`) |
| `percent` | int | Print progress % (legacy alias) |
| `mc_percent` | int | Motion-controller print progress % — Studio primary |
| `layer_num` | int | Current layer |
| `total_layer_num` | int | Total layers in plate |
| `mc_remaining_time` | int | Remaining time (minutes on observed P2S) |
| `remain_time` | int | Same remaining-time value (duplicate channel) |
| `prepare_per` | int | Prepare / slice-on-printer progress % |
| `gcode_file_prepare_percent` | string | Prepare progress as string (e.g. `"100"`) |
| `spd_lvl` | int | Speed preset level (Studio speed UI) |
| `spd_mag` | int | Speed magnitude % (e.g. `100`) |

#### Files / plate

| Field | Type | Meaning |
| --- | --- | --- |
| `gcode_file` | string | Active plate gcode path on printer (e.g. `/data/Metadata/plate_1.gcode`) |
| `file` | string | Often same as `gcode_file` |
| `print_type` | string | Job origin label (`local`, cloud variants, …) |
| `plate_id` | int | Selected plate id |
| `plate_idx` | int | Plate index (often same as `plate_id`) |
| `plate_cnt` | int | Number of plates in project |

#### Cloud / task identifiers

| Field | Type | Meaning |
| --- | --- | --- |
| `project_id` | string | Cloud project id; `"0"` / empty for pure LAN |
| `profile_id` | string | Cloud profile id; `"0"` for LAN |
| `task_id` | string | Task id (may be non-zero even on LAN — observed numeric string) |
| `subtask_id` | string | Subtask id; `"0"` for LAN placeholders |
| `subtask_name` | string | Display name (project / model name on printer UI) |
| `job_id` | string | Job id string; often `"0"` on LAN |
| `model_id` | string | MakerWorld / cloud model id; often empty |
| `design_id` | string | Design id; often empty |
| `canvas_id` | int | **Unknown** (observed `0`) |
| `batch_id` | int | **Unknown** (observed `0`) |
| `lan_task_id` | string | LAN task id; often `"0"` |

| Field | Type | Meaning |
