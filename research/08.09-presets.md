### 8.9. User presets

Cloud sync of the user’s private print / filament / printer presets. Studio drives the surface from [`GUI_App::start_sync_user_preset`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/GUI_App.cpp#L6212-L6347) on a worker thread after login; dirty local presets are pushed via [`sync_preset`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/GUI_App.cpp#L6072-L6210). Typedefs live in [`bambu_networking.hpp`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/Utils/bambu_networking.hpp#L137-L148); Studio resolves the symbols via `dlsym` ([NetworkAgent.cpp:345-350](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/Utils/NetworkAgent.cpp#L345-L350)). Progress / cancel lambdas are **per-call** arguments — not agent-level setters ([§8.2](08.02-callbacks.md)).

Neighbors: HTTP hosts / fingerprint headers ([§6.6](06.06-cloud-rest.md)); auth token ([§8.5](08.05-auth.md)).

#### 8.9.1. Common contract

**Callback typedefs** ([bambu_networking.hpp:137-148](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/Utils/bambu_networking.hpp#L137-L148)):

```cpp
using WasCancelledFn = std::function<bool()>;
using ProgressFn     = std::function<void(int progress)>;
using CheckFn        = std::function<bool(std::map<std::string, std::string> info)>;
```

**Shared REST surface.** All six entry points wrap one resource on the regional API host ([§6.6](06.06-cloud-rest.md)):

```
<method> /v1/iot-service/api/slicer/setting[/<setting_id>]?version=<bundle>&public=false
```

Auth is the usual `Authorization: Bearer <access_token>` and JSON content type. Response envelope (`message` / `code` / `error`) matches other iot-service calls.

**Setting ID prefixes** (observed in live responses):

| Type | ID prefix | Public counterpart |
|------|-----------|---------------------|
| `print` (process) | `PPUS…` | `GP…` |
| `filament` | `PFUS…` | `GFS…` / `GFL…` |
| `printer` (machine) | `PMUS…` | `GM…` |

**`values_map` keys `PresetCollection::load_user_preset` requires.** Studio rejects a preset unless the map contains, at minimum:

| Key | Source | Notes |
|-----|--------|-------|
| `version` | response `version` | Must be parseable by `Semver::parse`; preset is skipped if cloud major > Studio major. |
| `setting_id` | response `setting_id` | Stable identifier Studio writes back into the preset file. |
| `updated_time` | response `update_time` | **Unix seconds as a decimal string**, not the ISO string the server returns. |
| `user_id` | authenticated session | Server does not include it; caller must inject. |
| `base_id` | response `base_id` | Empty string when the preset is a custom root. |
| `type` | response `type` | `print` / `filament` / `printer`; top-level collection key in list response. |
| `filament_id` | response `filament_id` | Only mandatory when `type == "filament"` and `base_id` is empty. |
| `inherits` | inside `setting` | Pass-through from cloud; parent lookup during load. |
| (all other preset options) | inside `setting` | Merged into `DynamicPrintConfig` via `load_string_map`. |

**Stock vs full body.** The stock plugin’s list walk is **metadata-only** (`GET /slicer/setting` without per-id fetch). On a fresh machine the local cache is empty, so the loader gets a `setting_id` with no `setting` map to merge — presets stay invisible. Cross-device sync needs a full `values_map` (options from `setting`); the stock binary does **not** call `GET /slicer/setting/<id>` (that shape is known from direct probe only — see [§8.9.2](#892-bambu_network_get_setting_list2)).

**Studio sync sequence** ([`start_sync_user_preset`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/GUI_App.cpp#L6212-L6347)):

1. One-shot catalogue walk: `get_setting_list2(bundle_version, check_fn, progress_fn, cancel_fn)`. For each catalogue entry the plugin invokes `check_fn` with `{type, name, setting_id, updated_time}`; Studio’s closure returns `true` when `PresetCollection::need_sync()` says the row is newer than the on-disk copy. Progress 0–100 may drive a modal `ProgressDialog`.
2. On success Studio calls [`reload_settings`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/GUI_App.cpp#L6045-L6055) → `get_user_presets(&map)` → `preset_bundle->load_user_presets(...)`.
3. Background loop (100 ms tick, every 20 ticks): for each of `print` / `filament` / `printer`, dirty local presets go through [`sync_preset`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/GUI_App.cpp#L6072-L6210) → `request_setting_id` (create) or `put_setting` (update). Local deletions → `delete_setting` one-by-one.

Studio treats `values_map["code"] == "14"` as “preset quota exceeded” (`BBLUserPresetExceedLimit`) and stops further creates for that type. If `get_setting_list2` is missing, the NetworkAgent wrapper falls back to `get_setting_list` ([NetworkAgent.cpp:1257-1259](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/Utils/NetworkAgent.cpp#L1257-L1259)).

**Return convention.** Most symbols return `int`: `0` on success, non-zero on failure. `request_setting_id` returns the new `setting_id` string (empty on failure) and writes HTTP status into `*http_code`. There is no dedicated `BAMBU_NETWORK_ERR_*_PRESET_*` family in [§8.16](08.16-errors.md).


#### 8.9.2. `bambu_network_get_setting_list2`

**Parameters.**

| Name | Type | Meaning |
| --- | --- | --- |
| `agent` | `void*` | Opaque agent from `create_agent`. |
| `bundle_version` | `std::string` | Vendor profile version string (Studio: `preset_bundle->get_vendor_profile_version(BBL_BUNDLE)`). |
| `chk_fn` | `CheckFn` | Called per catalogue entry; `true` = Studio wants this preset synced / kept. |
| `pro_fn` | `ProgressFn` | Progress 0–100 (may be null). |
| `cancel_fn` | `WasCancelledFn` | Poll for abort (may be null). |

**Purpose.** List the user’s private cloud presets and optionally filter which rows to retain via `CheckFn`.

**Studio.** Primary pull inside [`start_sync_user_preset`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/GUI_App.cpp#L6261-L6278). Wrapper: [NetworkAgent.cpp:1251-1260](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/Utils/NetworkAgent.cpp#L1251-L1260).

**Plugin behaviour.** `GET /v1/iot-service/api/slicer/setting?public=false&version=<bundle_version>`. Evidence: MITM.

List response (metadata only — no `setting` payload in `private[]`):

```json
{
  "message": "success", "code": null, "error": null,
  "print":    { "private": [ /* Meta, … */ ], "public": [] },
  "printer":  { "private": [ /* Meta, … */ ], "public": [] },
  "filament": { "private": [ /* Meta, … */ ], "public": [] },
  "settings": []
}
```

Each `private[]` entry:

```json
{
  "setting_id": "PFUS7bf6d4b8df15d8",
  "name": "Bambu PLA Tough @BBL P1P 0.2 nozzle",
  "version": "0.0.0.0",
  "update_time": "2026-04-06 19:03:50",
  "base_id": null,
  "filament_id": null,
  "filament_vendor": null,
  "filament_type": null,
  "filament_is_support": null,
  "nozzle_temperature": null,
  "nozzle_hrc": null,
  "inherits": null,
  "nickname": null
}
```

`update_time` is `"YYYY-MM-DD HH:MM:SS"` UTC; for `CheckFn` / later `values_map`, convert to unix-seconds decimal string. For each entry invoke `chk_fn` with at least `{type, name, setting_id, updated_time}` (`type` = collection key `print` / `filament` / `printer`). Drive `pro_fn`; abort when `cancel_fn()` is true. Cache whatever Studio will later drain via `get_user_presets` (stock: metadata only).

Full body (stock does **not** call this; probe only):

```
GET /v1/iot-service/api/slicer/setting/<setting_id>
```

```json
{
  "message": "success", "code": null, "error": null,
  "setting_id": "PFUS7bf6d4b8df15d8",
  "name": "Bambu PLA Tough @BBL P1P 0.2 nozzle",
  "type": "filament",
  "version": "0.0.0.0",
  "base_id": null, "filament_id": null, "nickname": null,
  "update_time": "2026-04-06 19:03:50",
  "public": false,
  "setting": {
    "activate_air_filtration": 0,
    "compatible_printers": "\"Bambu Lab P1P 0.2 nozzle\"",
    "filament_type": "\"PLA\"",
    "...": "..."
  }
}
```

Values inside `setting` are already in `ConfigOption::serialize()` form (quoted scalars, semicolon-separated lists, …). Some keys arrive as JSON numbers; coerce to strings for the map. Owner `user_id` is never in the response — inject from the session ([§8.9.1](#891-common-contract)).

**Return.** `0` on success; non-zero on failure / cancel. Studio’s finish callback treats `ret == 0` as success before `reload_settings`.

#### 8.9.5. `bambu_network_request_setting_id`

**Parameters.**

| Name | Type | Meaning |
| --- | --- | --- |
| `agent` | `void*` | Opaque agent from `create_agent`. |
| `name` | `std::string` | Preset display name. |
| `values_map` | `std::map<std::string, std::string>*` | Keys/values Studio wants uploaded (and may receive `updated_time` back). |
| `http_code` | `unsigned int*` | out: HTTP status from the create call. |

**Purpose.** Create a new private cloud preset and return its `setting_id`.

**Studio.** [`sync_preset`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/GUI_App.cpp#L6083-L6135) when `setting_id` is empty / `sync_info` is `"create"`. Wrapper: [NetworkAgent.cpp:1219-1227](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/Utils/NetworkAgent.cpp#L1219-L1227). On empty return with `http_code >= 400`, Studio holds further creates for that type.

**Plugin behaviour.** `POST /v1/iot-service/api/slicer/setting` with body built from `name` + `values_map` (type / version / base_id / filament_id / setting options). Evidence: MITM.

Request:

```json
{
  "name": "<preset name>",
  "type": "filament|print|printer",
  "version": "<bundle version>",
  "base_id": "<parent system preset id or empty>",
  "filament_id": "<filament id or empty>",
  "setting": { "<option>": "<serialized value>", "...": "..." }
}
```

Success response:

```json
{ "message": "success", "code": null, "error": null,
  "setting_id": "PFUSdce8291f0b44ab",
  "update_time": "2026-04-21 17:56:43" }
```

Write `*http_code`. On success, return `setting_id` and typically update `values_map` with `updated_time` (unix seconds string) for Studio. Missing mandatory fields → HTTP 400 plain text (e.g. `field "version" is not set`); invalid `type` → HTTP 422 `{"detail":"Invalid input parameters"}`. Quota / business errors may surface as `values_map["code"] == "14"` (Studio-side).

**Return.** New `setting_id` on success; empty string on failure.
