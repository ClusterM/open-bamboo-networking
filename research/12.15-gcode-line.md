### 12.15. Arbitrary G-code (`gcode_line`)

Studio-built raw G-code passthrough. Used whenever there is no structured MQTT equivalent (or the printer lacks the matching capability bit). Plugin forwards only. Envelope: [§6.2](06.02-mqtt.md).

Builder: `MachineObject::publish_gcode` — [`DeviceManager.cpp:3726-3743`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/DeviceManager.cpp#L3726-L3743). Studio call sites include temperature/fan/axis/AMS fallbacks that emit M140/M104/M106/G28/… strings.

On a secured printer (Developer Mode off) the cleartext `param` must become `param_enc` and the frame is signed — [§10.3](10.03-mqtt-field-encryption.md) / [§10.4](10.04-mqtt-signing.md).

#### Request

| Field | Type | Notes |
| --- | --- | --- |
| `command` | string | `"gcode_line"` |
| `sequence_id` | string | Studio 20000–29999 |
| `param` | string | Raw G-code (often newline-terminated). Omitted when replaced by `param_enc` |
| `param_enc` | string | RSA-encrypted `param` on secured printers ([§10.3](10.03-mqtt-field-encryption.md)) |
| `user_id` | string | Optional; Studio adds the logged-in cloud user id when `NetworkAgent` exists |

```json
{
  "print": {
    "sequence_id": "20014",
    "command": "gcode_line",
    "param": ";comment\n"
  }
}
```

#### Response

Studio’s ack path only fires analytics (`ack_cmd_gcode_line`) for studio-range `sequence_id` — [`DeviceManager.cpp:3502-3510`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/DeviceManager.cpp#L3502-L3510). Firmware still echoes a full report on `…/report`.

| Field | Type | Notes |
| --- | --- | --- |
| `command` | string | `"gcode_line"` |
| `sequence_id` | string | Echo of the request |
| `param` | string | Echo of the sent G-code (when cleartext was used) |
| `result` | string | Observed `"SUCCESS"` (uppercase) |
| `reason` | string | Often mirrors `result` |
| `err_code` | int | `0` on success |
| `is_from_mqtt` | bool | Present on some firmwares |

#### Live example (LAN P2S)

**Request** (comment-only, safe):

```json
{
  "print": {
    "sequence_id": "20014",
    "command": "gcode_line",
    "param": ";obn-probe"
  }
}
```

**Response:**

```json
{
  "print": {
    "command": "gcode_line",
    "sequence_id": "20014",
    "param": ";obn-probe",
    "result": "SUCCESS",
    "reason": "SUCCESS",
    "err_code": 0,
    "is_from_mqtt": true
  }
}
```
