### 8.11. Camera

Cloud / remote camera URL minting and HMS print-error snapshot fetch through `libbambu_networking`. Studio resolves the symbols via `dlsym` ([NetworkAgent.cpp:370-393](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/Utils/NetworkAgent.cpp#L370-L393)). Typedefs live in [`NetworkAgent.hpp`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/Utils/NetworkAgent.hpp#L95-L120) (not in `bambu_networking.hpp`).

LAN liveview / file-browser URLs are often built by Studio itself and consumed by [`libBambuSource`](09-abi-bambusource.md) — that grammar is **not** duplicated here.

Neighbors: BambuSource tunnel / LAN URL shapes ([§9](09-abi-bambusource.md)); CTRL / TUTK framing on `:6000` ([§6.4](06.04-port-6000.md)); RTSP(S) ([§6.5](06.05-rtsp.md)); HTTP hosts ([§6.6](06.06-cloud-rest.md)); camera capability bits in `push_status` ([§12.1](12.01-status.md)).

#### 8.11.1. Common contract

**Async callback pattern.** All three symbols return `int` synchronously (accept / reject the call) and deliver the result through a `std::function` callback. Studio treats a non-zero sync return as “call not accepted” (e.g. `DeviceErrorDialog` requires `ret == 0` before waiting on the snapshot callback).

**Packed `dev_id` key** (camera URL symbols — not HMS). Studio concatenates:

```text
<serial>|<dev_ver>|<protocols_json>[|<channel>]
```

where `protocols_json` is one of Studio’s literals `""`, `"\"tutk\""`, `"\"agora\""`, `"\"tutk\",\"agora\""` indexed by `m_remote_proto` / capability. Agora refresh appends a fourth `|channel` segment ([MediaPlayCtrl.cpp:395-401](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/MediaPlayCtrl.cpp#L395-L401)).

**Studio accept gate.** For URL callbacks Studio requires `boost::starts_with(url, "bambu:///")`. Empty / other prefix → connection failed (`failed_code = 3`, or an integer parsed from a trailing `[N]` suffix). After a successful prefix match Studio **appends** client metadata the plugin may omit: `device`, `net_ver`, `dev_ver`, `refresh_url`, `cli_id`, `cli_ver` ([MediaPlayCtrl.cpp:504-510](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/MediaPlayCtrl.cpp#L504-L510)).

**LAN short-circuit (no plugin).** When LAN liveview / local file browser is available, Studio builds `bambu:///local/…`, `bambu:///rtsps___…`, or `bambu:///rtsp___…` itself and never calls these ABI symbols — see [§9.3](09.03-urls.md).

**Stock cloud mint.** Remote liveview hits `POST /v1/iot-service/api/user/ttcode` (Bearer; regional API host from [§6.6](06.06-cloud-rest.md)). This supersedes the older “`GET …/ttcode`” wording from [issue #49](https://github.com/ClusterM/open-bambu-networking/issues/49). TUTK / Agora tunnel setup after the URL is minted is vendor-locked inside `libBambuSource` ([§6.4](06.04-port-6000.md)).


#### 8.11.2. `bambu_network_get_camera_url`

**Parameters.**

| Name | Type | Meaning |
| --- | --- | --- |
| `agent` | `void*` | Opaque agent from `create_agent`. |
| `dev_id` | `std::string` | Packed key `serial\|dev_ver\|protocols_json[\|channel]` ([§8.11.1](#8111-common-contract)). |
| `callback` | `std::function<void(std::string)>` | Invoked with the minted URL (or a non-`bambu:///` failure string). |

**Purpose.** Mint a remote camera / tunnel URL for liveview, remote file browser, and other Studio consumers that need a `bambu:///` handle when LAN is unavailable.

**Studio.** Primary: [`MediaPlayCtrl::Play`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/MediaPlayCtrl.cpp#L495-L542) (remote liveview); [`RequestFileSystemUrl`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/MediaPlayCtrl.cpp#L845-L857); [`MediaFilePanel::fetchUrl`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/MediaFilePanel.cpp#L604-L637). Secondary: `PartSkipDialog` (`protocols[3]` = tutk+agora), `SendToPrinter` (`protocols[1]` = tutk) → `FileTransferTunnel`. Agora refresh re-enters the same ABI with a 4-part key via [`refresh_agora_url`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/MediaPlayCtrl.cpp#L395-L405). Wrapper: [NetworkAgent.cpp:1481-1489](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/Utils/NetworkAgent.cpp#L1481-L1489).

**Plugin behaviour.** Parse the packed key into `dev_id` / `dev_version` / protocol list. Stock cloud path (MITM stock `02.08.01.53`, `stock_status2.mitm`):

```http
POST /v1/iot-service/api/user/ttcode
Authorization: Bearer <access_token>
Content-Type: application/json

{"dev_id":"<serial>","dev_version":"<fw>","protocols":["tutk","agora"]}
```

Success envelope keys include `ttcode`, `authkey`, `passwd`, `region`, `type` (observed `"tutk"`), plus often-empty Agora fields (`stream_key`, `stream_salt`, `channel_name`, `app_id`, `streams`, `peers`, `rtm`). Assemble a URL Studio will accept (`bambu:///…`). Documented TUTK shape from [issue #49](https://github.com/ClusterM/open-bambu-networking/issues/49) (completeness; query assembly not re-verified under MITM+local reconstruct):

```text
bambu:///tutk?uid=<ttcode>&authkey=&passwd=&region=&device=&net_ver=&dev_ver=
```

(`device` / `net_ver` / `dev_ver` are usually filled by Studio after the callback.) Tokens are single-use and require a live cloud session. Agora non-empty responses / `bambu:///agora?…` assembly not captured here. Evidence: MITM (ttcode POST) + Studio source + issue #49 (URL grammar).

**TODO**: need exact stock assembly of `bambu:///tutk?…` / `bambu:///agora?…` from the ttcode JSON (Frida / stock log / MITM + local reconstruct).

**Return.** `0` when the async call is accepted; non-zero if the symbol / agent is unavailable. Result is delivered via `callback`.

#### 8.11.4. `bambu_network_get_hms_snapshot`
