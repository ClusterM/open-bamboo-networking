### 8.12. MakerWorld / Mall

MakerWorld / Mall surface through `libbambu_networking`: homepage preference / For-You feed, print-task enrichment for rating, mall rating CRUD, OSS picture upload for ScoreDialog, and a few URL accessors. Studio resolves the exports via `dlsym` ([NetworkAgent.cpp:372-392](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/Utils/NetworkAgent.cpp#L372-L392)).

This is **not** REST-only: cloud HTTPS, async callback ABI, local / SSO URL builders, and client-signed object-store PUTs all appear here.

Neighbors: device-panel cover task JSON ([§8.10.6](08.10-http.md#8106-bambu_network_get_subtask_info) `get_subtask_info`); WebView SSO ticket ([§8.6.6](08.06-bind.md)); cloud-presigned print upload contrast ([§8.8.3](08.08-print-abi.md#883-bambu_network_start_local_print_with_record)); HTTP hosts ([§6.6](06.06-cloud-rest.md)).

Studio does **not** `dlsym` STATUS-only shims such as `del_rating_picture_oss` / `get_model_instance_id` / `get_model_rating_id` — they are out of this chapter.

**`get_subtask` vs `get_subtask_info`.** Different URLs and consumers — do not conflate:

| Symbol | Input | Expected output | Studio consumer |
| --- | --- | --- | --- |
| `get_subtask_info` ([§8.10.6](08.10-http.md#8106-bambu_network_get_subtask_info)) | `subtask_id` string | JSON blob; hero thumbnail from `context.plates[<plate_idx>].thumbnail.url` | `DeviceManager` → printer-card cover |

**Rating pipeline** (hot path):

```
push_status (task_id)
  → StatusPanel::update_model_info
      → get_subtask(BBLModelTask{task_id})   // fills design_id / instance_id / …
      → set_modeltask
  → MachineObject::update_model_task          // requires instance_id > 0
      → get_model_mall_rating(instance_id)
      → ScoreDialog (optional)
          → get_oss_config → put_rating_picture_oss (per image)
          → put_model_mall_rating(rating_id, score, content, images)
```

Without a live `get_subtask` (`instance_id == 0`) Studio never opens the in-app rating path. Browser fallback: `get_model_mall_detail_url` → rewrite to MakerWorld rating page.

**Regional hosts.** Mall page hosts from Studio `GUI_App::get_model_http_url`: `https://makerworld.com/` (US) / `https://makerworld.com.cn/` (CN). Cloud REST paths below are relative to the regional API host from [§6.6](06.06-cloud-rest.md) unless noted.

**Evidence tags:** `MITM` / `mw_probe` (`plugin_runner --action mw_probe`) / `source` / [issue #49](https://github.com/ClusterM/open-bambu-networking/issues/49).

**Return convention.** Sync `int`: `0` on success (or “call accepted” for async symbols). `BAMBU_NETWORK_ERR_GET_RATING_ID_FAILED` (`-21`) when `put_model_mall_rating` gets `rating_id <= 0` ([bambu_networking.hpp:35](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/Utils/bambu_networking.hpp#L35)). **Purpose.** Upload one rating picture to object storage with **client-side** signing (unlike cloud-presigned print upload in [§8.8.3](08.08-print-abi.md#883-bambu_network_start_local_print_with_record)).

**Studio.** ScoreDialog per image ([StatusPanel.cpp:6441](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/StatusPanel.cpp#L6441)); collected paths go into `put_model_mall_rating`’s `images` vector. Wrapper: [NetworkAgent.cpp:1735-1739](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/Utils/NetworkAgent.cpp#L1735-L1739).

**Plugin behaviour.** Parse `config`, single-shot `PUT` of the picture body. Scheme from endpoint host: `aliyuncs.com` → Aliyun OSS V1; otherwise AWS SigV4. STS `securityToken` folds in as the vendor session-token header. Cross-validated in [issue #49](https://github.com/ClusterM/open-bambu-networking/issues/49).

```py
# --- AWS SigV4 (S3-style endpoint) ---
scope = date_stamp + "/" + region + "/s3/aws4_request"          # date_stamp = YYYYMMDD
CanonicalRequest = "PUT\n" + canonical_uri + "\n" + canonical_query + "\n" \
                 + canonical_headers + "\n" + signed_headers + "\n" + hex(SHA256(payload))
#   signed_headers = "host;x-amz-content-sha256;x-amz-date"  (+ ";x-amz-security-token" if STS)
#   x-amz-content-sha256 header value = hex(SHA256(payload))
StringToSign = "AWS4-HMAC-SHA256\n" + amz_date + "\n" + scope + "\n" + hex(SHA256(CanonicalRequest))
#   amz_date = YYYYMMDDTHHMMSSZ ; its date part must equal date_stamp
signing_key = HMAC(HMAC(HMAC(HMAC("AWS4"+secret, date_stamp), region), "s3"), "aws4_request")
signature   = hex(HMAC(signing_key, StringToSign))
headers["Authorization"] = "AWS4-HMAC-SHA256 Credential=" + akid + "/" + scope \
                         + ", SignedHeaders=" + signed_headers + ", Signature=" + signature
headers["x-amz-date"] = amz_date
headers["x-amz-content-sha256"] = hex(SHA256(payload))
if security_token: headers["x-amz-security-token"] = security_token

# --- Aliyun OSS V1 (CN endpoint) ---
StringToSign = "PUT\n" + Content-MD5 + "\n" + Content-Type + "\n" + Date + "\n" \
             + CanonicalizedOSSHeaders + CanonicalizedResource
#   Date = RFC1123 GMT ; CanonicalizedResource = "/<bucket>/<object>"
#   CanonicalizedOSSHeaders = sorted "x-oss-*:" lines incl. x-oss-security-token
signature = Base64(HMAC-SHA1(access_key_secret, StringToSign))
headers["Authorization"] = "OSS " + access_key_id + ":" + signature
headers["Date"] = Date
if security_token: headers["x-oss-security-token"] = security_token
```
