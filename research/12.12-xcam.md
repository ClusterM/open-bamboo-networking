### 12.12. AI / xcam

Studio-built `xcam.xcam_control_set`. Plugin forwards only. Envelope: [§6.2](06.02-mqtt.md). Inbound `xcam.*` / `xcam_status` in `push_status`: [§12.1.5](12.01.05-fields-camera-ai.md); `xcam.cfg` bit decode: [§12.1](12.01-status.md#printxcamcfg--integer-decimal-not-hex).

#### `xcam.xcam_control_set`

Control an AI/vision module and optional halt sensitivity.

| name | type/values | notes |
|---|---|---|
| `sequence_id` | string | Studio counter; example fixed to `"20000"` |
| `command` | string | constant `"xcam_control_set"` |
| `module_name` | string | printing_monitor, spaghetti_detector, buildplate_marker_detector, first_layer_inspector, pileup_detector, clump_detector, airprint_detector, plate_offset_switch, fod_check, or model_movement_check |
| `control` | bool | new protocol |
| `enable` | bool | old protocol duplicate |
| `print_halt` | bool | builder sends true |
| `halt_print_sensitivity` | string | optional: never_halt/low/medium/high |

**Reply parsing:** `[`src/slic3r/GUI/DeviceCore/DevPrintOptions.cpp:39-164`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/DeviceCore/DevPrintOptions.cpp#L39-L164)`, dispatched at `DeviceManager.cpp:3596`.
