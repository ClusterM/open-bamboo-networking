### 12.4. Temperatures / chamber / extruder

Studio-built temperature and extruder selection MQTT commands. Plugin forwards only. Envelope: [§6.2](06.02-mqtt.md). Hub: [§12](12-mqtt.md).

#### `print.set_bed_temp`

Set bed target temperature.

| name | type/values | notes |
|---|---|---|
| `sequence_id` | string | Studio counter; example fixed to `"20000"` |
| `command` | string | constant `"set_bed_temp"` |
| `temp` | int | °C |

**Reply parsing:** `DevBed::ParseV1_0`, dispatched at `[`src/slic3r/GUI/DeviceManager.cpp:3223`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/DeviceManager.cpp#L3223)`.

```json
{
  "print": {
    "sequence_id": "20000",
    "command": "set_bed_temp",
    "temp": 60
  }
}
```

#### `print.select_extruder`

Select the active extruder. Builder: [`DevCtrl.cpp:63`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/DeviceCore/DevCtrl.cpp#L63).

| Field | Type | Notes |
| --- | --- | --- |
| `extruder_index` | int | Target extruder |

```json
{
  "print": {
    "sequence_id": "20000",
    "command": "select_extruder",
    "extruder_index": 1
  }
}
```

**Response.** No dedicated ack parser; Studio updates local target optimistically ([`DevCtrl.cpp:65-70`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/DeviceCore/DevCtrl.cpp#L65-L70)).

#### `print.set_extrusion_length`

Manual extrude / retract by signed length. Builder: [`DeviceManager.cpp:1854`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/DeviceManager.cpp#L1854).

| Field | Type | Notes |
| --- | --- | --- |
| `extruder_index` | int | Extruder index |
| `length` | int | Caller double truncated to int |

```json
{
  "print": {
    "sequence_id": "20000",
    "command": "set_extrusion_length",
    "extruder_index": 0,
    "length": 10
  }
}
```

**Not live-probed** (moves filament).
