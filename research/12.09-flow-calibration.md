### 12.9. Flow-ratio calibration

Studio-built `flowrate_*` MQTT commands. Plugin forwards only. Envelope: [§6.2](06.02-mqtt.md). Hub: [§12](12-mqtt.md).

#### Overview

Parallel to PA, Studio drives flow-ratio calibration with:

| Command | Request keys | Response |
|---------|--------------|----------|
| `flowrate_cali` | `nozzle_diameter`, `tray_id`, `filaments[]` with `tray_id`, `bed_temp`, `filament_id`, `setting_id`, `nozzle_temp`, `def_flow_ratio`, `max_volumetric_speed`, `extruder_id`, `ams_id`, `slot_id` | `result` / `reason` (same pattern as `extrusion_cali`) |
| `flowrate_get_result` | `nozzle_diameter` | `filaments[]` with `tray_id`, `nozzle_diameter`, `filament_id`, `setting_id`, `flow_ratio`, `confidence` |

`flowrate_cali` sends `tray_id` and `nozzle_diameter` at the top level, with the per-filament parameters repeated inside `filaments[]`.

**Note — live behavior.** On a P2S over LAN MQTT, `flowrate_get_result` produced **no response** (the request was accepted but nothing was published back within a few seconds), so its response shape is unverified against real hardware. The field list above is taken from the request builder and response parser in Bambu Studio source only.

#### Command builders (Studio)

#### `print.flowrate_cali`

Start automatic flow-ratio calibration.

| name | type/values | notes |
|---|---|---|
| `sequence_id` | string | Studio counter; example fixed to `"20000"` |
| `command` | string | constant `"flowrate_cali"` |
| `tray_id` | int | first item |
| `nozzle_diameter` | string | first item |
| `filaments` | array<object> | tray_id, bed_temp, filament_id, setting_id, nozzle_temp, def_flow_ratio, max_volumetric_speed, extruder_id, ams_id, slot_id |

**Reply parsing:** `[`src/slic3r/GUI/DeviceCore/DevCalib.cpp:301-313`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/DeviceCore/DevCalib.cpp#L301-L313)`.

```json
{
  "print": {
    "sequence_id": "20000",
    "command": "flowrate_cali",
    "tray_id": 0,
    "nozzle_diameter": "0.4",
    "filaments": [
      {
        "tray_id": 0,
        "bed_temp": 60,
        "filament_id": "GFA00",
        "setting_id": "GFSA00",
        "nozzle_temp": 220,
        "def_flow_ratio": "0.98",
        "max_volumetric_speed": "12.0",
        "extruder_id": 0,
        "ams_id": 0,
        "slot_id": 0
      }
    ]
  }
}
```

#### `print.flowrate_get_result`

Fetch flow-ratio calibration results.

| name | type/values | notes |
|---|---|---|
| `sequence_id` | string | Studio counter; example fixed to `"20000"` |
| `command` | string | constant `"flowrate_get_result"` |
| `nozzle_diameter` | string | diameter |

**Reply parsing:** `[`src/slic3r/GUI/DeviceCore/DevCalib.cpp:288-299`](https://github.com/bambulab/BambuStudio/blob/12f17b06f4f537f9c03162d08bb70cf733c42839/src/slic3r/GUI/DeviceCore/DevCalib.cpp#L288-L299),322-323`.

```json
{
  "print": {
    "sequence_id": "20000",
    "command": "flowrate_get_result",
    "nozzle_diameter": "0.4"
  }
}
```
